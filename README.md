# Instagram Clone

A responsive Instagram-style web application built using React.js, Bootstrap, and JSON Server.

## Technologies Used

- React.js
- Bootstrap
- JSON Server
- Axios / Fetch API

## Features

- Instagram-style sidebar
- User profile management
- Profile update functionality
- Follow / Unfollow system
- CRUD operations
- GET, POST, and DELETE API requests
- Real-time UI updates
- JSON Server database integration

## Follow / Unfollow System

The application implements a Follow/Unfollow system using CRUD operations.

- **Follow:** Sends a POST request to create a following relationship.
- **Unfollow:** Sends a DELETE request to remove the relationship.
- Changes are immediately reflected in the user profile.

## API

JSON Server is used as a mock REST API for storing and managing application data.
